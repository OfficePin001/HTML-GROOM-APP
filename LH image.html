What is an image?

An image is the visual representation for anything. Images are needed for website development, it helps website to look attractive for visitors. Websites without images will definitely look boring to interact with.

To add images to our page we have to make use of the source (src=" ") attributes. This source attribute could also be used to link images from external server. E.g

<img src="https://google.image.com " alt="google image"/>

But for now, we are adding image from our folder.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

    <img src="image.jpg">

</body>
</html>

OUTPUT




Images that doesn't display on the screen of the browser usually have an alternative text but this text is optional, It is also use to tell little information about the image if it does not shows. To add this text to the image we have to include an attribute to our image tag called Alternative (alt=" "). Take note, this text in the alternative attribute doesn't appear unless your images does not show because of the following cases, if it loads slowly, slow server, the image has been deleted from the directory or an invalid url in the source attribute (src=" ").

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>
<!-- image with alternative text value-->
    <img src="imge.jpg"alt="image of html vs css">
<br/>
<!-- image without alternative text value-->
    <img src="imge.jpg"alt=" ">

</body>
</html>

OUTPUT






The image was broken because of invalid url, also in the first image there is a text value while the other does not have a text value. This justifys that the alternative in not necessary but it will help your user to have idea of what type of image is meant to be displayed.

Now, do you observed that in our first example of image, our image does not have a definite size, this is where these attributes width=" " and height=" " comes in to play. They give the specific size to our image.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

    <img src="image.jpg"alt="image of html vs css"width="130px"height="190px">
</body>
</html>

OUTPUT





Now the image displayed, has a definite size with the help of height and width, also these attributes are attributes the style tag in html. You will learn more about it in CASCADING STYLESHEET (CSS) class.

While using the style tag for image we use it as an attribute (style=" "). But the output for both attribute width, height and nested attributed width, height will be the same.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
.    <title>Page title</title>
</head>
<body>

    <img src="image.jpg"alt="image of html vs css" style="width:130px; height:190px;">
</body>
</html>

OUTPUT

What is a figure.

Figure in html is a self-contained content and typically referenced as a single unit. It can be an image, diagram, illustration and lot more.

The figure could have a caption attached to it or have it to be alone. The figure tag (<figure></figure>) and it caption tag (<figcaption></figcaption>) are both content element tags. The image, diagram, etc goes in the figure tag while the text goes in the caption tag.

Example

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<figure>     <img src="code.jpg"alt="image of a programmer " style="width:230px; height:190px;"> <figcaption>figure 1.1 Programming language </figcaption>
</figure>
</body>
</html>

OUTPUT
