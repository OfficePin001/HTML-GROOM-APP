What is HTML?

Hyper Text Markup Language (HTML), is a front-end programming language and the foundation of many website development, the HTML is the structural aspect of a website development which gives meaning to a website.

There are different versions of HTML language used in front-end programming. Here we are going to learn about the HTML5 version and how to write its standard snippet. The HTML5 is the modern Hyper Text Markup Language used by many programmers.

To write our codes in HTML5 we are to declare it as doctype in this form.

<!DOCTYPE html>

The HTML5 has different tags performing different functions, for example : <body>
<html>
<style>
<div>
and many other tags that we will come across during the process of learning.

Snippet
This are the first compulsory features that a standard HTML5 needs to function properly.

Example of HTML5 snippet
<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

</body>
</html>

OUTPUT



The output is displayed blank because we haven't added any elements to the <body></body> tag or included any other elements or tags to display on the screen.


Now let add something to our code so we can have our results display on the screen.


<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>
   <div>
    <a href="www.code.com">link</a>
   </div>
</body>
</html>

OUTPUT



link

We added the anchor tag (<a></a>) which you will learn more about in LINKS. Now you can see the result displayed on the output screen, this shows that we have added an element called the anchor tag and we put a content "link" so it will be displayed on the screen.




Example of image and link

We will be adding an image to our code including a link, this will be done using the image tag (<img>) and anchor tag (<a></a>).

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>
   <div>
    <img src="image.jpg"alt="image">
    <a href="www.code.com">link</a>
   </div>
</body>
</html>

OUTPUT



Link

But we are not furthering into image and link for now but we will when we get there.
