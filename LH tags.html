IN THIS CLASS WE WILL LEARN ABOUT TAGS

what are tags?

Tags are elements enclosed by an angle bracket (</>) used to give instructions to the code editor.

We have two type of tag element Which are

  1. Content element tags
  2. Empty element tags

This tags are what gives the code editor what function you want it to perform in HTML, except for some special functions which are called CHARACTER Entity. This character entity does not required angle brackets to surround it eg. &nbsp, &#129590 and many others, but this function requires "ampersand" (&) to give the command to the editor, learn more in link break, horizontal rule and non breakable space.

The words surrounded by angle brackets are also called elements. Here in this class you will be given some tags needed in HTML5 programming.

NOTE: The content in the angle brackets are written in lowercase except for the Document type
<! DOCTYPE html>
<html></html>

Here is the list of a few HTML5 tags.

TAGS NAME FUNCTION
<html></html> hyper text markup language tag It tells the editor it is a html function so other html tags are contained in it.
<head></head> head tag It carries the meta tag and page title, it is outside the body tag but inside the html tag
<title></title> page title This is the name given to the page which displays on the tab of the browser.
<meta/> meta data tag It is used to give more information about a web page to the browser or search engines.
<body></body> body tag In this tag all content of the code are contained.
<p></p> paragraph tag It gives a new paragraph when used.
<a></a> anchor tag It links two different pages together.
<div></div> division tag It divides content starting it on another new line like the paragraph tag.
<span></span> span tag It is an inline tag unlike the division tag this span tag joins contents together in one line.
<img/> image tag It adds image to our display content. It is an empty element tag.
<link/> link tag It connects the html to an external file.
<form></form> form tag It tells the editor that you are working on form.
<table></table> table tag It tells the editor that this is a table.
<input/> input tag It creates an input in you display.
<br/> line break tag It takes other elements behind it to the next line.

And so much more. All tags cannot be listed here only if you don't want to learn other things.

So with the help of tags the editor displays elements on the Web page.
