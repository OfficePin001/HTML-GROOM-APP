What is a form?

Form is used to collect user data, it could be a login form,sign in form, feedback form and so many others.

To define html form we have to make use of the <form> tag, attributes of the form tag could be action, target, onSubmit, id, class, name, autocomplete, e.t.c

Elements which could be nested inside a form tag are:

  • Input tag
  • Label tag
  • Button tag
  • Textarea tag
  • Dropdown list element

Here in this class we will explain each tags and you will learn how to build a responsive website.

To build a responsive website we will make use of the meta tag it is an empty content tag, it is nested in the head element

<head>
    <meta/>
</head>

If we want your website to respond to the size of any device we will have to add these attributes to the meta tag name and content. The name defines the function while the content performs the function.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8"/>
   <meta name="viewport"
content="width=device-width,
initial-scale=1.0"/>
   <title>Page title</title>
</head>
<body>

</body>
</html>

OUTPUT




It has no literal effect on the main screen but if we have a content in our page it will fit the size of any device, that is the main purpose of making our website responsive.

Now let's proceed to our form elements, first we are going to begin with the input tag.

The input tag allows the form to collect the users information. There are different input type we have the text, numbers, email, password, radio, check box and more. Let's see how the different types of input works.

NOTE: some of the input type doesn't display properly without the value attribute. Such as the button, reset and submit type.
