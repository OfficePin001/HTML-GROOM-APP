How to embed videos in our html file

To embed videos in our html file we have the video (<video></video>) element with it's src=" " attribute or you can nest the source (<source></source>) element inside the video element, also we have to include a valueless attribute "controls" to the opening tag of the video element in order to allow it function properly. Other attributes of the video element are: control, autoplay, muted, loop, poster, [height & width] (optional, it may be included in your CSS file. You will learn CSS after completing html). These attributes are valueless in the sense that they do not have values, just like that of the content editable in the previous class.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<video src="video.mp4" controls></video>

</body>
</html>

OUTPUT




Let's add the loop attribute to our video element and see our results.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<video src="video.mp4" controls  loop></video>

</body>
</html>

OUTPUT




Now you see that the video keeps on playing repeatedly without end, therefore this 'loop' attribute allows the browser to play the video repeatedly. You can set the width and height of the video to your desired size.

Now let's add audio to our page.

To add audio to our page we have to use the audio element (<audio></audio>), it is the same with the video element but for the audio we do not have the 'poster, width and height attributes ' but other attributes are same as the video element.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<audio src="audio.mp3" controls></audio>

</body>
</html>

OUTPUT




Also if we are to add the loop attribute to our audio element it will play the audio repeatedly.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<audio src="audio.mp3" controls  loop></audio>

</body>
</html>

OUTPUT




Let learn how to embed video and audio with the source element, also the while using the source element we can add more than one video or audio at the same time.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<video controls>
    <source src="video.mp4" type="video/mp4"></source> </video>
<br/><br/>
<audio controls>
    <source src="audio.mp3" type="audio/mp3"></source> </audio>
</body>
</html>

OUTPUT
