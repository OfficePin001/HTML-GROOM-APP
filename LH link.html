What is a link?

Link is a connection between files, pages and other browsers.

Link exist in different form, for example the most popularly know links has "https" this shows that the link is secured, links with "http" are mostly local host link like the ones in your code editor before it is hosted publicly, links with "www" are world wide website links that can be viewed anywhere. Although, links in html is similar to that, the only difference is you cannot just add links to your code on it own, you have to follow some procedures, like knowing the correct tag and attributes to use. Attributes are features inside a tag for content element tags the attributes are contained inside the opening tag.
E.g
<a href="www.facebook.com" target="example"></a> (for content element tags)
<img src="image.jpg" alt="coding"/> (for empty element tags).

Let's move further.

We are familiar with the anchor tag (<a></a>). The anchor tag is use to link pages together, either your page or an external page. But most time if you are to link your own page, the page must be in the same folder and you are not advised to use the local host address of that page to prevent errors when you want to host your code publicly.

While using the anchor tag we have to include an attribute known as the 'hyper text reference' (href) in this form [href=" "] in between the double quote you will add the link to your page.

example
If this is our folder and we want to link our current page as shown in the image to the next page we will have to make use of the anchor tag.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>example</title>
</head>
<body>
   <div>
    <a href="next page.html">link</a>
   </div>
</body>
</html>

Now let's to link another external file, like the our cascading stylesheet (CSS)

This is a file that gives our html file beauty and some special features, you will learn about CSS after you have finished learning html. Now to link your CSS file to your html file you have to use this empty content tag called the link tag (<link/>). It is not used for css only but others like fonts and favicon (Web icons).

In addition, for link we don't make use of href attribute only we also make use of the attribute called Relationship (rel=" "), the Type attribute (type=" ") and Media (media=" ") this attributes tells the browser what you want your link to be. But here we will make use of " href, rel and type".

css code (name: our.css) 
body{
      background-color:blue ;

      color:yellow ;
}


NOTE:   The link tag must be in the head, because it is a css file it will help the css to load fast before the html appears on the screen.
