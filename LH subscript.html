What is subscript and superscript?

Subscript renders lower baseline and small texts while superscript renders raised baseline and small texts. This texts are rarely used only on special cases.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<!-- The subscript -->
<p>The subscript </p>

<p> N<sub>2</sub> + H<sub>2</sub> &rarr; NH<sub>3</p>

<p> N<sub>2</sub> + H<sub>2</sub> &rarr; 2NH<sub>3</sub></p><br/>

<!-- The superscript -->
<p>The superscript </p>

<p> = x<sup>3</sup> + 3x + 2x<sup>2</sup> + 6 </p>

<p> = x<sup>3</sup> + 2x<sup>2</sup> + 3x + 6 </p><br/>

</body>
</html>

OUTPUT



The subscript

N2 + H2 → NH3

N2 + H2 → 2NH3


The superscript

= x3 + 3x + 2x2 + 6

= x3 + 2x2 + 3x + 6

What is a preformatting text?

Preformatting text is the <pre> elements which renders texts exactly as it was written in your code editor.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<!-- This will not render the text exactly -->
    <p>
       My
       Name
       Is
       John
       Doe
    </p>
<!-- This will render the text exactly -->
    <pre>
       My
       Name
       Is
       John
       Doe
    </pre>

</body>
</html>

OUTPUT



My Name Is John Doe 

                My
                Name
                Is
                John 
                Doe

Let touch a little bit of content editable

Content editable is an attribute that does not require a value if it is inside the starting tag. It is a global attribute and it can have two possible values "true" or "false" this tells the editor if the content will be editable or not.

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<p contenteditable>
Hello World! I am an editable content, you can try to rewrite my content.
</p>
</body>
</html>

OUTPUT



Hello World! I am an editable content, you can try to rewrite my content.
