What is text formatting?

Text formatting is adding special features to text, to help the Web users know important parts in a paragraph or sentence. There are different elements used to format texts.

Elements used to format texts
Names Tags
Bold tag (<b></b>)
Italic tag (<i></i>)
typewriter text tag (<tt></tt>)
Emphasis tag (<em></em>)
Quote tag (<q></q>)
Strike tag (<s></s>)
Code text tag (<code></code>)
Mark tag (<mark></mark>)
Underline tag (<u></u>)
Strong tag (<strong></strong>)
Big tag (<big></big>)
Small tag (<small></small>)

Example of how text formatting works
<!DOCTYPE html>
<html lang="en">

</head>
<body>

<br/>

<br/>

<br/>

<br/>
<tt> I am a typewriter text </tt>

<br/>

What is table?

Table is the representation of data in tabular form. This datas are stored in rows and columns. To tell our editor we are working on table we will nest our elements in the table tag (<table></table>).

    Elements nested in the table tag to get a perfect results are:

  • The table head (<thead></thead>)
  • The table body (<tbody></tbody>)
  • The table row (<tr></tr>)
  • The table heading (<th></th>)
  • The table details (<td></td>)

While creating a table the <th> is nested inside the <thead> while the <td> is nested inside the <tbody>. But both the <th> and the <td> must be nested inside the <tr> before going into any other tag,because the <tr> tells the editor the numbers of rows you want to create.

Example
<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>

<table>
   <thead>
      <tr>
         <th>
          First name
         </th>
         <th>
          Last name
         </th>
      </tr>
   </thead>
   <tbody>
      <tr>
         <td>
          John
         </td>
         <td>
          Doe
         </td>
      </tr>
      <tr>
         <td>
          Clara
         </td>
         <td>
          Silver
         </td>
      </tr>
   </tbody>
</table>

</body>
</html>

OUTPUT



First name Last name
John Doe
Clara Silver
