First let's begin with ELEMENTS

what is an element?

Element is any content contained in a code.

We can also say it is combination of tags (opening tag and closing tag) and a content known as element content. It takes this form:

  • <p> I am the element content </p>

  • <p>(opening tag)

  • I am the element content(element content)

  • </p>(closing tag) 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <p>
      I am the element
    </p>
</body>
</html>

OUTPUT



I am the element

We also have the nested elements

In some cases html tags can contain more than one elements. Those scenarios are called nested elements, where an element is nested inside another element. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <b>
      <i>
      I am nested
      </i>
    </b>
</body>
</html>

OUTPUT



I am nested

Finally we have the empty elements

This empty element doesn't have a closing tag they are single tags. E.g <br/>  <img/>  <hr/>  <link/> e.t.c it can also work if the forward slash (/) is not present. E.g <br>  <img>  <hr>  <link> e.t.c


Now we move to COMMENTS

What is a comment in html?

A comment is a way of adding messages, texts or description in our code, making it accessible, easier to read and understandable by the programmer. It is visible only in your code but not in the page. A comment contains the angular brackets (<>) an exclamation mark (!) and four hyphens (-), it takes this form (<!-- -->). 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <!-- I am the comment but I
 will not display on your
 page. -->
    <b>
      <i>
      I am nested
      </i>
    </b>
</body>
</html>

OUTPUT



I am nested

Comments will help you know the type of function you used (for those who easily forgets things) and help you find where any error may occur. For Example if you have a code of 3533 lines and in your code runs error in the form element, now going back to you code it will be difficult to find the form element without a comment, but if you included a comment before or after writing the form element then you can easily find it. But it is preferable to write the comment before the writing code.
