IN THIS CLASS WE WILL LEARN ABOUT ELEMENTS AND COMMENTS

First let's begin with ELEMENTS

what is an element?

Element is the combination of tags (opening tag and closing tag) and a content popularly call element content. It takes this form: 

  <p> This is the element content </p>
       
             <p>(opening tag)
             
    I am the element content(element content) 
      
             </p>(closing tag)
                

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <p>
      I am the element 
    </p>
</body>
</html>

OUTPUT



I am the element


note:

For every element, there is always an opening and closing tag. And we will learn more about tags in the next class.

examples of opening and closing tags 
<html> </html>

<a> </a>

<sub> </sub>

<body> </body>

OUTPUT



I am the element content I am the element content I am the element content I am the element content

If you observe closely all element contents are joined together, and this is because we didn't add the line break tag (<br>) to our code. But you will learn more about it in line break, horizontal rule and non breakable space class.


We also have the nested elements

In some cases html can contain more than one elements. Those scenarios are called nested elements, where an element is nested inside another element. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <b>
      <i>
      I am nested
      </i>
    </b>
</body>
</html>

OUTPUT



I am nested

Finally we have the empty elements

This empty element doesn't have a closing tag they are single tags. E.g <br/>  <img/>  <hr/>  <link/> e.t.c it can also work if the forward slash (/) is not present. E.g <br>  <img>  <hr>  <link> e.t.c


Now we move to COMMENTS

What is a comment in html?

A comment is a way of adding messages or describing contents in your code, making it accessible, easier to read and understandable by the programmer. It is visible only in your code but not in the page. A comment contains the angular brackets (<>) an exclamation mark (!) and four hyphens (-), it takes this form (<!-- -->). 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Example</title>
</head>
<body>
    <!-- I am the comment but I
 will not display on your
 page. -->
    <b>
      <i>
      I am nested
      </i>
    </b>
</body>
</html>

OUTPUT



I am nested

Comments will help you know the type of code and help you find where an error occur. For Example if you have a code of 3533 lines and in your code error appears in the form when you run it, going back to you code it will be difficult to find the form code without a comment, but if you included a comment before or after writing the form code you can easily find it. But it is preferable to write the comment before the code.
