What is HTML?

Hyper Text Markup Language (HTML), is a front-end programming language and the foundation of website development and others, the HTML is the bony work of a website development which gives meaning to a website.

Here we are going to learn how to write HTML5 code which is the modern Hyper Text language. It has a special way to declare the modern HTML which is HTML5.

To declare HTML5 we write the code in this form

<!DOCTYPE html>

The HTML5 has different tags performing different functions, for example : <body>
<html>
<style>
<div>
and many other tags that we will come across during the process of learning.

Snippet
This are the first compulsory features that a standard HTML5 needs to function properly.

Example of HTML5 snippet
<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>
</body>
</html>

OUTPUT



The output is displayed blank because we haven't added any elements to the <body></body> tag or included any other elements or tags to display on the screen.


Now let add something to our code so we can have our results display on the screen.


<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title</title>
</head>
<body>
   <div>
    <a href="www.code.com">link
   </div>
</body>
</html>

OUTPUT



link

We added the anchor tag (<a></a>) you learn more about it in LINKS. Now you can see the result displayed on the output screen, this shows that we have added the anchor tag and we put an element "link" so it will be displayed on the screen.




Example of image and link

We added an image to our code including a link, this is done using the image tag (<img>) and anchor tag (<a></a>).

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <title>Page title
</head>
<body>
   <div>
    <img src="image.jpg" alt="image">
    <a href="www.code.com">link</a>
   </div>
</body>
</html>

OUTPUT



Link
